# 🧠 Simon Says Game

An interactive browser-based memory game built using **HTML, CSS, and JavaScript**. The game challenges players to remember and repeat an increasingly complex sequence of colors.

## 🚀 Live Demo

👉 https://adnan-codes-118.github.io/Simon-Says-Game/

---

## 🎮 Features

* Interactive UI with smooth animations
* Sound effects for each button
* Progressive difficulty (levels increase)
* Real-time progress bar
* Game-over animation with score display

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Animations & Styling)
* JavaScript (Game Logic)

---

## 📂 Project Structure

```
├── index.html
├── style.css
├── app.js
```

## ⚙️ How to Run Locally

1. Clone the repository

```
git clone https://github.com/Adnan-codes-118/Simon-Says-Game.git
```
